Create workspace

source /home/user/projects/SAP_GenAI/env/bin/activate


Create a virtual environment using the following command:
python3 -m venv ~/projects/SAP_GenAI/env --upgrade-deps
Activate the env virtual environment like this and make sure it is activated:
source ~/projects/SAP_GenAI/env/bin/activate
